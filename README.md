# Mi Dolce Valen 🍰

Sistema web para la gestión de clientes.

## 🚀 Tecnologías usadas
- Frontend: React (Vite)
- Backend: Java Spring Boot
- Base de datos: MySQL

## ⚙️ Cómo ejecutar el proyecto

### 1. Iniciar base de datos
- Abrir XAMPP
- Iniciar Apache y MySQL

### 2. Ejecutar Backend
- Ir a carpeta backend/java-api
- Ejecutar Spring Boot

### 3. Ejecutar Frontend
- Ir a carpeta frontend
- Ejecutar:
  npm install
  npm run dev

## 🧪 Funcionalidades
- Crear cliente
- Listar clientes
- Editar cliente
- Eliminar cliente
